# learnmate-ai
LearnMate AI - A multi-agent AI-based personalized e-learning assistant integrating LLMs, NLP, information retrieval, security, and Responsible AI.

## Local Development

Image uploads require local Tesseract English language data. See the
[OCR Setup Guide](docs/ocr-setup.md) if image uploads report that OCR is
unavailable.

Google account access is optional during local development. See the
[Google Sign-In Setup Guide](docs/google-auth-setup.md) to create the Web
client ID and add it to the backend and frontend environment files.
The implemented controls and explicitly accepted prototype risks are recorded
in the [Authentication Security Notes](docs/authentication-security.md).

## Commercialization Vision

LearnMate AI proposes a freemium student offering and future institutional licensing model. The current project is an academic prototype and does not process payments or enforce subscriptions. See the [LearnMate AI Commercialization Plan](docs/commercialization-plan.md) for the target market, proposed plans, deployment strategy, go-to-market roadmap, and Responsible AI commitments.
